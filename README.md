Чтобы запустить вам необходимо иметь:
1.Unity Hub
2.Unity Editor версии 6000.3.12f1 или выше
3.GitHub Desktop(опционально)
Зайдите в unity hub, нажмите на вкладку add, в выпадающем списке выберите project from disk, сюда вставьте путь к папке, в которой находится github репозиторий, дождитесь загрузки проекта и запустите его.
